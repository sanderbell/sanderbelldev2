# Проверка интерфейса Huihui

6 октября 2026 года. Область проверки: приватный чат `/hui/`, вход, настройки и установка PWA на десктопе и мобильных экранах.

Интерфейс получил более читаемые темы, удобные зоны нажатия, отдельные черновики по чатам и устойчивую обработку потоковых ответов. Для скачка поля при фокусе устранены лишние пересчёты высоты редактора и принудительная прокрутка страницы. Геометрия при открытии клавиатуры проверена моделированием visual viewport в Chromium и WebKit; поведение экранной клавиатуры на реальном телефоне требует проверки на устройстве.

## Исправления

| Область | Результат |
| --- | --- |
| Внешний вид | Обновлены типографика, интервалы, карточки стартовых запросов, редактор, панель чатов и заголовок. |
| Адаптация | Проверены ширины 320, 390, 768, 1024 и 1440 px в светлой и тёмной темах. Код и таблицы прокручиваются внутри своих блоков. |
| Мобильное поле | Фиксированный корневой контейнер учитывает высоту и смещение visual viewport. Изменения объединяются через requestAnimationFrame; фокус использует preventScroll. Высота редактора не зависит от промежуточных кадров клавиатуры. Поля ввода на сенсорных устройствах имеют шрифт 16 px. |
| Отправка | На сенсорной клавиатуре Enter вставляет перенос строки; отправка доступна кнопкой или Ctrl/Cmd+Enter. Составление следующего сообщения возможно во время ответа. |
| Черновики | Текст сохраняется отдельно для каждого чата и нового разговора, включая перезагрузку. Подготовленные изображения остаются в своём черновике в текущей вкладке. |
| Поток ответа | Читается последний JSON-фрагмент без завершающего переноса строки. Частичный ответ сохраняется при обрыве; доступен повтор запроса и остановка. |
| Вложения | Подготовка файлов показывает статус и временно блокирует отправку. Последовательная обработка соблюдает лимит четырёх изображений при пересекающихся загрузках. Очистка истории при нехватке места не удаляет изображения из отправляемого запроса. |
| Навигация | Мобильная панель удерживает фокус, скрытая панель исключена из навигации, Escape возвращает фокус. Настройки доступны из заголовка. |
| Доступность | Именованные элементы, состояния радиокнопок, клавиатурный выбор темы/акцента, объявления ошибок и окончания ответа, декоративные иконки скрыты от скринридера. Контраст проверен axe в обеих темах. |
| Удаление | Один чат можно вернуть через Undo. Удаление всей истории требует отдельного подтверждения и очищает старую историю и текстовые черновики. |
| Вход | Корректные этапы пароля и PIN, валидация видимых полей, показ пароля, смена аккаунта, ошибки подключения и полноценное задание пароля после восстановления/приглашения. |
| PWA | Инструкция установки доступна на русском и английском. Выход закрывает диалоги, останавливает ответ и скрывает чат до перехода к входу. |
| Политика безопасности | Цвета акцентов перенесены из встроенных стилей в CSS. Работа темы, акцентов и высоты редактора проверена с текущим production CSP. |

## Проверки

Пройдено 48 браузерных проверок: 24 сценария в каждом из двух движков. Сборка, lint и проверки приватных маршрутов/PWA также проходят.

Браузерные сценарии находятся в `tests/hui.spec.ts` и `tests/hui-login.spec.ts`; запускаются в Chromium и WebKit. Проверки охватывают черновики, отправку, остановку, ошибки, вложения, нехватку места, поиск, переименование, редактирование, экспорт, удаление, вход, PIN, приглашения, восстановление пароля, адаптацию, доступность и CSP.

```sh
npm ci
npx playwright install chromium webkit
npm run test:hui
npm run test:private
npm run lint
```

Для установленного Chrome на macOS можно использовать:

```sh
HUI_CHROME_PATH='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' npm run test:hui
```

Браузерные проверки используют синтетические чаты и моки cloud/Identity; они подтверждают работу интерфейса, а реальный вход и ответы провайдера требуют проверки с действующей сессией. Сценарии защиты приватных маршрутов и сетевого PWA отдельно проходят в `test:private`. Автоматическая проверка axe покрывает проверенные состояния и не заменяет ручную проверку скринридером.
